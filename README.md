# SHINOBI: REQUIEM (versão autocontida)

Esta versão usa **um único `index.html`** com CSS e JavaScript embutidos. Isso evita o problema de a página carregar o HTML sem carregar os arquivos de estilo e do jogo.

## Instalar no GitHub Pages pelo celular
1. Abra o repositório `soucuususu/Shinobi-game`.
2. Abra `index.html` e escolha editar (ícone de lápis).
3. Substitua TODO o conteúdo pelo `index.html` deste pacote. Salve com commit.
4. Espere o GitHub Pages atualizar e recarregue a página. Se continuar antiga, faça uma recarga forçada ou abra em uma aba anônima.

Alternativa: envie somente este `index.html` para a raiz do repositório, substituindo o antigo. Não precisa enviar CSS ou JS separados.

## Controles
Celular: setas para andar, esquiva, pulo, ataque e técnica especial.
PC: A/D ou setas para mover; J/Z atacar; K/X técnica; Espaço/W/↑ pular; Shift/L esquivar; E treinar; Esc pausar.

## Conteúdo desta base
Tela de título e criação, personalização, revelação aleatória de aldeia, cenário 2D desenhado em canvas, movimentação, pulo duplo, esquiva, combos, especial elemental, inimigos, vida/chakra/XP/níveis, itens, treino e salvamento local.

É uma base jogável inicial, ainda não a campanha final inteira. A história dos 15 anos, as 30+ aldeias completas e os 25 elementos ainda precisam ser construídos.
